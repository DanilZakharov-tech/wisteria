# WISTERIA 2D

Игра для iPhone в браузере: глава «Новая соседка», реальные задания и развитие личного блога.

## Запуск

- npm ci
- npm run dev
- npm test
- npm run build

## Игровые системы

12 сцен, 24 решения, 10 связанных миссий; отношения с 10 персонажами открывают личные приглашения. Пять навыков дают особые миссии на уровне 3. Три подробных Reels-брифа каждый день 30-дневного сезона; личные задания по желанию. 10 локаций, 5 визуальных образов, 10 покупок за игровые монеты, 6 размещаемых предметов декора.

Общий уровень 1–60: в первых уровнях открываются локации и покупки, на каждом новом уровне начисляется бонус монет. Это не 60 отдельных сюжетных глав. Первая глава заканчивается клиффхэнгером.

Instagram: ручной ввод реальных показателей, стартовая аудитория и цель 5000, средние просмотры, подписки с публикаций и сравнение форматов. Автоматического доступа к Instagram нет.

## Сохранения

Zustand persist: wisteria-campaign-v3. Старые wisteria-save-v1 и wisteria-story-2d-v2 не удаляются. XP, монеты, метрики и отношения переносятся; новая расширенная история начинается с первой сцены. В настройках доступны экспорт и проверяемый импорт JSON. Перед новой игрой предлагается резервная копия.

## Проверка браузером

Установить Chromium: npx playwright install chromium. Запустить npm run dev в отдельном терминале, затем npm run test:e2e. Для другого адреса задать BASE_URL. Для уже установленного Chromium задать PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH. Артефакты проверки сохраняются в test-artifacts.

Сценарий проходит главу, подтверждает задачи, перезапускает сохранение, покупает и надевает одежду, размещает декор, вводит метрики и экспортирует резервную копию. Проверяет размеры iPhone 13 и SE и ошибки JavaScript. Дополнительная проверка импорта и офлайн-запуска выполнялась на локальной production-сборке.

## Ограничения выпуска

Одна законченная сюжетная арка, дальнейшие главы не заявлены готовыми. Иллюстрации созданы по референсам; точная фотографическая идентичность не гарантируется. Реальные действия подтверждает игрок. Данные остаются в браузере устройства; автоматической синхронизации между устройствами нет. PWA устанавливается через Safari → Поделиться → На экран Домой. Проверено в мобильной эмуляции Chromium; на физическом iPhone тест не проводился.

Для дополнительной проверки: npm run preview, затем BASE_URL=http://localhost:4174 npm run test:offline. Перед этим выполнить test:e2e для создания тестовой резервной копии.
